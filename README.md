# Shiko

_思考 / 試行 — Thought and experimentation_

**Exile Research | Softworks Division**  
Adaptive Cognitive Memory Engine

## Purpose

Shiko investigates the development of a persistent, adaptive and associative memory engine that operates independently of the architecture or language model consuming it.

The immediate objective is to provide agents with reliable cross-session continuity, automatic contextual recall and an evolving understanding of acquired knowledge and experiences.

## Core principles

- Memory persists independently of sessions and inference providers.
- Relevant memories are automatically recalled before inference.
- Memories and associations can be reinforced through experience.
- Activation decays over time without necessarily deleting knowledge.
- Contradictory information is identified, reconciled and historically preserved.
- Memory management should minimize reliance on generative inference.
